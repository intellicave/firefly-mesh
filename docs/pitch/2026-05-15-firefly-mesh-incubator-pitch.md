## 一、项目介绍

我们致力于构建**国内领先的企业级 多agent 组织协同平台 Firefly**——让企业内每位员工自带的 AI agent通过统一协议层接入到组织协同中枢，获得跨人协作、人工仲裁、共享知识、完整审计的协同能力，把"每个员工各自用 AI"升级为"组织级 AI 协同网络"。

项目已获得**清华x北大 黑客松第二名与全球奖**，并已签约首批电商行业付费客户，验证了"多agent + 组织协同"路径在国内市场的真实需求。

## 二、市场机会与产业痛点

2025-2026 年，中国正进入 **AI-native 企业的爆发期**：根据 Anthropic、QuestMobile 等多源数据估算，中国 20-200 人规模的知识型企业中，**70% 以上员工已在日常工作中使用至少一种 AI工具**。

但 AI 全员普及带来了新的、被严重低估的**组织级摩擦成本**：

1. **沟通成本**——跨员工协作时 agent 的上下文必须人工对接，平均一次任务交接耗损 15-30 分钟
2. **agent 孤岛**——每位员工的 agent 不知晓公司其他动态，无法跨人调用知识库与技能
3. **合规缺失**——市面上 agent 框架未严格设计人工审计环节（Human in the loop），对于合规、金融、政企等场景完全不可用

与此同时，三大跨厂商标准在 2026 年成型：**Google A2A v1.2**（agent-to-agent 通信协议）、**agentskills.io**（跨 runtime 的 skill 标准化格式）、**Anthropic MCP**（工具接入协议）。这意味着"组织级 agent 协议层"作为新一代企业 AI 基础设施的品类窗口正在打开。

## 三、解决方案与差异化

Firefly把企业内多个员工的 AI 助手组织成"一支可被指挥的协同团队"，三个核心差异化能力：

**1. 多 Agent 智能调度**——任务自动拆解：管理者下达战略指令 → 平台基于组织图、技能匹配与负载情况，把任务拆解成子任务并分派给对应部门 / 员工的 AI 助手 → 跨员工 agent 通过协议层结构化通信完成协作 → 多级人工审批后闭环。从"一句话需求"到"跨部门交付"的全链路自动化，是同类自治派 multi-agent 框架不具备的组织级调度能力。

**2. SOP 流程编排**——把企业的标准业务流程（客户咨询响应、促销方案生成，自媒体运营等）固化为可复用的 agent 协同模板**把AI从个人提效升级为组织级流程资产沉淀。**

**3. 强人工仲裁与可审计**——跨人 agent 通信中的高风险动作由协议层强制双向人工确认；权限分层（公司 / 部门 / 个人）+ 审计日志 + 全量对话回放，对应SOC2 等合规要求。

护城河：

**(a) 行业知识沉淀**——skill  与 SOP 模板可被新接入 agent 即时继承；跨客户复用后形成行业知识积累，客户用得越深、组织 know-how 沉淀越厚、切换越难。**把"AI 工具采购"转化为"AI 组织资产建设**。

**(b) 学术深度与工程实践**——多 Agent 智能调度算法 + SOP 编排引擎 + HITL 双向协议状态机 + 跨 runtime 兼容协议层 + agent 强化学习 + 边缘原生分布式架构，**6 项自研核心技术叠加**；**其中多项核心算法论文已在投ICLR 等国际顶级 AI 会议**，依托团队人工智能 / 分布式系统的多学科研究底座。

## 四、平台、商业模式与杭州落地

**已上线服务：** `hub.firefly-mesh.com`（API + WebSocket 生产服务）+ `firefly-mesh.com`（开发者门户）。已签约首批电商行业付费客户；社区已有上百位OPC成员参与。

**商业模式：** 针对**高频跨人协作企业**按垂类深耕落地：

- **电商运营**：选品决策、商家沟通、客服话术统一、营销活动复盘等高频协同流程
- **管理咨询**：客户调研、行业研究、方案撰写、内部多轮审稿等多人协作流程
- **OPC 协同**：让 N 个OPC个体通过 Firefly 形成团队，共同承接超出单人产能的大型项目交付与多角色协作——把"一群单干的一人公司"组合成"一支可被指挥的虚拟公司"

每个垂类先做一个"开箱即用 SOP 包"打透标杆客户（已在电商垂类签下首批），再横向复制到同类企业。短期收入来自垂类企业 SaaS 按席位订阅 + 顾问/培训服务；中期通过 SOP / skill 模板的跨客户复用形成行业 best-practice 数据沉淀。

**杭州落地：** 杭州是中国电商之都与ai agent前沿区域——我们首批客户与 Q3 目标客户高度集中在长三角电商生态，垂类深耕的标杆与复制路径在本地最短。
