## 一、项目介绍

我们致力于构建**国内领先的企业级多 agent 组织协同平台 Firefly**——让每位员工自带的 AI agent 通过统一协议层接入组织协同中枢，把"每个员工各自用 AI"升级为"组织级 AI 协同网络"。

项目已获得**清华 × 北大黑客松第二名与全球奖**，已签约首批电商付费客户。

---

## 二、市场机会与痛点

2025-2026 年中国 AI-native 企业爆发：知识型组织内 **70% 员工已使用 AI agent**（Anthropic / QuestMobile 数据）。但全员普及暴露三大组织级摩擦：

1. **沟通成本**——跨员工 agent 上下文人工对接，单次交接耗损 15-30 分钟
2. **agent 孤岛**——每位员工的 agent 不知晓公司其他动态，无法跨人调用知识与技能
3. **合规缺失**——主流 agent 框架缺少人工审计设计，金融 / 政企无法落地

同期 **Google A2A v1.2、Anthropic MCP、agentskills.io** 三大跨厂商标准成型——"组织级 agent 协议层"品类窗口正在打开。

---

## 三、解决方案与差异化

Firefly 把企业内多个员工的 AI 助手组织成"一支可被指挥的协同团队"：

1. **多 Agent 智能调度** —— 任务自动拆解：管理者下达战略指令 → 平台基于组织图、技能匹配与负载情况，把任务拆解成子任务并分派给对应部门 / 员工的 AI 助手 → 跨员工 agent 通过协议层结构化通信完成协作 → 多级人工审批后闭环。实现跨部门交付的全链路自动化
2. **SOP 流程编排** —— 把企业的标准业务流程（客户咨询响应、促销方案生成，自媒体运营等）固化为可复用的 agent 协同模板**把AI从个人提效升级为组织级流程资产沉淀。**
3. **强人工仲裁与可审计** —— 跨人 agent 通信中的高风险动作由协议层强制双向人工确认；权限分层（公司 / 部门 / 个人）+ 审计日志 + 全量对话回放，对应SOC2 等合规要求。

**护城河：**
- **(a) 行业知识沉淀**——SOP / skill 模板跨客户复用形成组织 know-how 飞轮，**把"AI 工具采购"转化为"AI 组织资产建设"**
- **(b) 学术 + 工程双壁垒**——多 agent 调度 / SOP 编排 / HITL 协议 / 跨 runtime / 边缘原生架构 / agent 强化学习 6 项自研技术叠加，核心算法论文已在投 ICLR 等AI顶会

## 四、商业模式与杭州落地

**已上线：** `hub.firefly-mesh.com`（API 生产服务）。已签约首批电商行业付费客户；社区已有上百位 OPC 成员。

**垂类深耕：** 

- **电商运营**：选品决策、商家沟通、客服话术统一、营销活动复盘等高频协同流程
- **管理咨询**：客户调研、行业研究、方案撰写、内部审稿
- **OPC 协同**：让 N 个OPC个体通过 Firefly 形成团队，共同承接超出单人产能的大型项目交付

每垂类先做"开箱即用 skill+SOP 包"打透标杆，再横向复制。收入来自垂类企业 SaaS 按席位订阅 + 顾问/培训服务

**杭州落地：** 中国电商之都 + AI agent 前沿区域，首批与 Q3 目标客户高度集中在长三角电商生态，复制路径最短。
